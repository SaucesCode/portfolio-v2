## 1. Executive Summary & Strategic Repositioning

In Phase 2C, we finalized an architectural engineering portfolio tailored primarily for technical recruiters, engineering leaders, and systems peer review. 

Under **Phase 2D**, we execute an intentional strategic pivot to serve a high-value commercial clientele:
1. **Clients seeking full-stack web application and custom business system development** (founders, operations leads, and businesses requiring scalable React/Next.js/Node/Django platforms).
2. **Clients seeking bespoke WordPress websites, custom Full Site Editing (FSE) themes, high-converting digital storefronts, and premium web design** (boutique brands, agencies, and e-commerce merchants).

The objective is to establish an **unmistakably memorable, bespoke digital product experience**. The website must look and feel like an award-winning creative studio or digital atelier—demonstrating exceptional visual taste, typography, and frontend craft **without overwhelming non-technical clients** with developer dashboards, fake operating systems, terminals, or heavy 3D gimmicks.

### Direction A: "DE MESA — Digital Craft" (The Editorial Atelier)

#### Identity & Concept
Direction A presents James as an **independent master craftsperson**. It rejects cold, impersonal corporate tech aesthetics in favor of the tactile warmth and intellectual poise of an elite European design monograph. 

It tells clients: *"Your website will not look like an off-the-shelf template. It will be custom-crafted with bespoke typography, thoughtful whitespace, and lightweight, high-performance code."*

#### Visual Language & Tokens
- **Background:** Soft warm unbleached linen (`#fbf9f5`).
- **Typography:** Deep carbon charcoal (`#161614`) for primary headings, warm muted stone (`#747269`) for metadata, and terracotta accent (`#b84218`) for editorial emphasis.
- **Borders & Dividers:** Subtle architectural hairlines (`#dfdbd2`).
- **Typography Hierarchy:** High-contrast serif headlines (`Newsreader` / `Playfair Display`) paired with clean modern sans-serif body (`Geist Sans`).

#### The Signature Interaction: "Finished Product vs. Behind the Build"
Clients want to see the gorgeous live website, but also want reassurance that the underlying code isn't fragile spaghetti. 
- **The Split Reveal:** Featured cards display an interactive vertical divider line with an ergonomic drag handle (`⇄ DRAG REVEAL`).
- **Left Pane (Finished Product):** Showcases the client-facing UI: editorial lookbook typography, responsive layout, product cards, and live store links.
- **Right Pane (Behind the Build):** Reveals the underlying technical craftsmanship: clean `theme.json` configuration, zero-plugin block architecture, sub-1s LCP score, and database schema excerpts.
- **Mobile Adaptation:** On mobile screens, the drag slider automatically switches to a frictionless toggle pill: `[● Finished Site] [Behind the Build]` with zero drag latency.

- **Typography Hierarchy:** Bold, geometric Swiss neo-grotesque display headers (`Geist Sans Display` bold weight) paired with precise tabular numerals.

#### The Signature Interaction: "Business Impact vs. Technical Blueprint"
Rather than pure aesthetic reveals, Direction B focuses on **commercial return on investment (ROI)**:
- **Client Service Pillars:** Three prominent solution cards directly beneath the hero:
  1. *Full-Stack Business Systems* (React, Next.js, Node.js, PostgreSQL)
  2. *Custom WordPress & FSE* (Zero-bloat Gutenberg themes & stores)
  3. *High-Converting Commerce* (Headless stores, speed optimization)
- **Interactive Project Teaser (`Portfolio CMS` & `Kinetix Athletics`):**
  - **Mode 1 (Business Value Delivered):** Displays measurable client outcomes:
    - Content Publishing Velocity: **75% reduction in publishing time**.
    - Software Runtime Costs: **$0/month in recurring CMS subscriptions**.
    - Data Ownership: **100% owned PostgreSQL database**.
  - **Mode 2 (Technical Blueprint):** Switches to the Prisma schema, JWT authentication flow, and sub-10ms query execution benchmarks.
- **Conversion Pathway:** Dedicated "Book a 20-Min Project Scope Call" buttons integrated directly into project showcases and mobile bottom docks.

## 5. Interactive Project Reveal Storyboard

The "Finished vs. Behind-the-Build" reveal satisfies both non-technical business owners and CTOs:

```
[STATE 1: IDLE / DEFAULT CLIENT VIEW]
┌──────────────────────────────────────────────────────────────────────────────────┐
│  High-resolution visual preview of the live website, typography, and layout.    │
│  Client sees immediate beauty, brand alignment, and responsiveness.             │
└──────────────────────────────────────────────────────────────────────────────────┘
                                      │
                         User hovers or drags slider
                                      ▼
[STATE 2: INTERACTIVE SLIDER REVEAL (DESKTOP)]
┌───────────────────────────────────────┬──────────────────────────────────────────┐
│  FINISHED WEBSITE (60%)               │ ⇄ DRAG │  BEHIND THE BUILD (40%)         │
│  Lookbook layout & imagery            │ HANDLE │  Clean JSON tokens & schema     │
└───────────────────────────────────────┴────────┴──────────────────────────────────┘
                                      │
                         Touch viewport or accessibility toggle
                                      ▼
[STATE 3: MOBILE & ACCESSIBLE TABBED MATRIX]
┌──────────────────────────────────────────────────────────────────────────────────┐
│  [ ● View Finished Product ]              [ ○ View Behind the Build ]            │
│                                                                                  │
│  Tapping switches view instantaneously without dragging or translation delays.   │
│  Full screen-reader semantic markup (`role="tablist"` and `aria-selected`).      │
└──────────────────────────────────────────────────────────────────────────────────┘
```

### Motion & Reduced-Motion Accessibility (WCAG 2.3.3 Level AAA)
- **Standard Motion:** 150ms spring transition on cursor drag with hardware-accelerated CSS `clip-path` masking. Zero layout shift.
- **Reduced Motion:** When `@media (prefers-reduced-motion: reduce)` is enabled, the draggable curtain is replaced with clean, instantaneous side-by-side tabs.
